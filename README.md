# 🎯 Job Hunt AI — مصر وإنجلترا

أداة ذكاء اصطناعي مجانية للبحث عن وظايف في مصر وإنجلترا مع تراكر للتقديمات.

## المميزات
- تحليل السيفي بـ Gemini AI
- بحث حقيقي عن وظايف في مصر وإنجلترا
- فلتر Visa Sponsorship
- تراكر تقديمات مع CSV export

## خطوات الرفع على Streamlit Cloud

### 1. احصل على Gemini API Key مجاني
- روح على: https://aistudio.google.com
- سجّل بحساب Google
- اضغط "Get API Key" ← "Create API Key"
- انسخ المفتاح

### 2. ارفع على GitHub
- سجّل في https://github.com (مجاني)
- اضغط "+" ← "New repository"
- اسمه: `job-hunt-ai`
- اضغط "Create repository"
- ارفع الملفين: `app.py` و `requirements.txt`

### 3. شغّل على Streamlit Cloud
- روح على: https://share.streamlit.io
- سجّل بحساب GitHub
- اضغط "New app"
- اختار الـ repo بتاعك
- Main file path: `app.py`
- اضغط "Deploy"

### 4. استخدم التول
- افتح الـ URL بتاع الموقع
- حط Gemini API Key في الـ Sidebar
- ابدأ!
